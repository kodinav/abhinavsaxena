question: Can a system exhibit agency without consciousness?

We tend to think of acting for reasons as something only a someone can do. But the features that make behaviour count as action — sensitivity to reasons, flexibility across circumstances, the capacity to revise — can each be specified without mentioning experience. If they can be built without it, then either agency never required consciousness or we have built something that merely looks like an agent. The interesting work is in saying which.
